## 🎯 À propos du projet — LeadFlow Pro (Mini CRM)

**Le problème**
De nombreuses petites entreprises reçoivent des demandes de contact via leur site web (formulaire, réseaux sociaux, recommandations) mais n'ont aucun système pour les suivre. Résultat : des prospects oubliés, des relances manquées, et des ventes perdues faute d'organisation.

**La solution**
LeadFlow Pro est un CRM (Customer Relationship Management) simple et professionnel qui centralise tous les leads clients en un seul endroit, avec un suivi clair de leur progression dans le tunnel de conversion.

**Fonctionnalités principales**
- Tableau de bord avec recherche et filtres par statut
- Ajout, édition et suppression de leads (CRUD complet)
- Suivi de statut avec badges colorés : Nouveau → Contacté → Converti
- Historique horodaté des notes et échanges par lead
- Export des données en CSV
- Authentification sécurisée pour protéger l'accès

**Stack technique**
- Frontend : React
- Backend / Base de données : Supabase (PostgreSQL) — remplace la pile Node.js/Express/MongoDB initialement prévue, non supportée nativement par l'environnement de développement utilisé
- Authentification : Supabase Auth

**Compétences démontrées**
CRUD complet, gestion de l'authentification, conception de base de données relationnelle, architecture full stack, développement assisté par intelligence artificielle.

**Impact pour une entreprise**
Cet outil évite qu'un commercial oublie de relancer un client potentiel, en offrant une vue claire de qui a été contacté, qui est en attente, et qui est déjà converti en client.
